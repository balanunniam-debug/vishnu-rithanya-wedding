VISHNU PRASATH & RITHANYA — WEDDING INVITATION WEBSITE
======================================================

WHAT'S INCLUDED
- Responsive, mobile-friendly wedding invitation website
- Couple names and invitation message (English + Tamil)
- Reception and Muhurtham details
- Countdown to Muhurtham
- Photo gallery slots for the couple's three original photos
- Venue directions link (Google Maps search)
- WhatsApp invitation sharing
- Gentle original browser-generated melody; starts only after Play music is tapped
- No paid libraries or backend required

IMPORTANT: ORIGINAL COUPLE PHOTOS
The previous-chat photos could not be confidently located in the available Library, so they are not embedded in this package yet. To add them without altering faces, copy the originals into:
  assets/photos/couple-outdoor.jpg  (couple outdoors; bride in maroon saree)
  assets/photos/couple-beach.jpg    (couple standing at the beach)
  assets/photos/couple-rings.jpg    (hands and rings close-up)

Use those exact filenames. JPG is recommended. If your originals are PNG, convert them to JPG or update the image filename in index.html.
The gallery placeholders automatically disappear when the correct image files are present.

HOW TO PREVIEW
1. Extract the ZIP.
2. Open index.html in Chrome, Edge, or Firefox.
3. Click "Play music" to hear the generated melody.
4. Test "Get directions" and "Share this invitation".

FREE PUBLISHING WITH GITHUB PAGES
1. Sign in to https://github.com/ or create a free account.
2. Create a new public repository, e.g. vishnu-rithanya-wedding.
3. Upload all files and folders from this extracted package. Keep index.html at the repository root.
4. Open repository Settings -> Pages.
5. Under "Build and deployment", select "Deploy from a branch".
6. Select branch "main" and folder "/ (root)", then Save.
7. Wait for GitHub Pages to finish publishing. The public URL will appear in Settings -> Pages, usually:
   https://YOUR-USERNAME.github.io/vishnu-rithanya-wedding/
8. Open that public URL on a phone and share it through WhatsApp.

NOTES
- A public live URL does not exist until you publish it through a hosting provider.
- Internet is required for Google Fonts and Google Maps. The main site itself is static.
- Venue link opens a Google Maps search for "Vivaas Mahal, Dhali Road, Periyakulam Pirivu"; confirm the exact pin before sharing widely.
- The uploaded music is stored at assets/wedding-music.m4a. Visitors must tap Play music; autoplay is not used.
- Dates and times are set to India Standard Time (IST).
